How to Redeem a Muse Invite Code (Step by Step)

A Muse invite code gives your new account bonus tokens. This guide walks you through redeeming it, and fixes the most common errors.

The 48-hour rule: enter the code within 48 hours of joining Muse. After that, it will not redeem on that account.

Step 1 — Create your Muse account first

Create your account through the official Muse route at muse.ai. The code does not create an account — it only adds the bonus to an account that already exists.

Step 2 — Open the redeem screen

  1. In the app: Settings → Redeem token.
  2. On the web: Settings → General → Usage → Redeem invite code.

Step 3 — Enter the code exactly

Type or paste the six characters exactly as shown. Copy-paste avoids typos.

Step 4 — Confirm and check your balance

Confirm the redemption, then check the usage or tokens screen inside your account. That screen is the source of truth for what was credited. The amount, eligibility, and timing depend on Muse's current invitation terms and your account.

Common errors and fixes

  • “Code is used up” — the code has run out of redemptions. You need a different, still-active code.
  • “Invalid code” — re-check the six characters, one by one. A single wrong character is the most common cause.
  • Nothing happens / window passed — confirm you are still within 48 hours of joining. If the window closed, the code cannot redeem on that account.
  • Wrong account — make sure you are signed into the account you joined within the last 48 hours.

Frequently asked questions

Do I have to enter the code right after signing up?

You have 48 hours from joining to enter the code. After that window closes, the code can no longer be redeemed on that account.

Where do I see my tokens after redeeming?

Check the usage or tokens screen inside your Muse account. The in-app redeem screen is the source of truth for what was credited.

I got a message that the code is used up. What now?

That code has run out of redemptions. You need a different, still-active invite code.

Can I redeem a code on an account I created more than 48 hours ago?

No. The 48-hour window runs from when you joined. If it has passed, the code will not redeem on that account.
