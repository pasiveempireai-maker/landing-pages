# Landing pages collection

Landing pages sharing a Muse invite code, with a step-by-step redeem guide.

## Live pages

- English invite code page: https://free-muse-tokens.vercel.app/
- Hebrew invite code page: https://free-muse-tokens-he.vercel.app/
- English redeem guide: https://free-muse-tokens.vercel.app/guide.html
- Hebrew redeem guide: https://free-muse-tokens-he.vercel.app/guide.html

## Folders

- `muse-invite/` — English pages (deployed as `free-muse-tokens`)
- `free-muse-tokens-he/` — Hebrew pages (deployed as `free-muse-tokens-he`)

Each folder is deployed on Vercel from its own project, with its own `sitemap.xml` and `robots.txt`.

Independent pages sharing one user's code. Not Meta, and not the Muse product team. For official product and availability information, use https://muse.ai.
